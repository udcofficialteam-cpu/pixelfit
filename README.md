# PixelFit — One-time AI download notice update

This update changes only the explanatory message in the Background Remover section. Existing tools, styles, scripts, contact and FAQ are not changed by this patch.

## Apply to GitHub
1. Extract this ZIP.
2. In your `pixelfit` repository, choose **Add file → Upload files**.
3. Upload only `index.html` into the repository root and replace the existing file.
4. Commit changes. Vercel should redeploy from the connected repository.

The notice explains that the browser may reuse the AI model, while accurately noting that clearing browser storage can require another download.
