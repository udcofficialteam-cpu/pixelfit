PixelFit bilingual FAQ update

This update adds a bilingual Help Center / FAQ section with an English and Roman Urdu toggle. It also preserves the current Contact dialog fix.

To apply the update:
1. Extract this ZIP.
2. Open your GitHub repository named pixelfit.
3. Upload index.html, styles.css, and app.js to the repository root, replacing the existing files with the same names.
4. Commit the changes.
5. Wait for Vercel's automatic deployment to finish, then hard-refresh the live website (Ctrl+F5).

No backend, API key, database, or build command is required.
