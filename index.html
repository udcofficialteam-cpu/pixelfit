HELP CENTER

Visitor FAQs & Guide

Practical answers to common image resizing, compression, conversion and wallpaper questions.Image resize, compression, conversion aur wallpaper se mutalliq aam sawalon ke asaan jawab.

Can I select a ready-made size for Instagram, Facebook or WhatsApp Status?Kya Instagram, Facebook ya WhatsApp Status ke liye ready-made size select kar sakta hoon?

Yes. In Step 02, open “Quick size presets” and choose a preset such as Instagram Square, Portrait or Story/Reel, TikTok, or WhatsApp Status (1080 × 1920). You do not need to enter the dimensions manually. Preview the crop before exporting.

Ji haan. Step 02 mein “Quick size presets” khol kar Instagram Square, Portrait ya Story/Reel, TikTok, ya WhatsApp Status (1080 × 1920) select karein. Dimensions khud likhne ki zaroorat nahi. Export se pehle crop ka preview zaroor dekh lein.

How do I make a square photo for Pak Army or another official form?Pak Army ya kisi official form ke liye square photo kaise banaoon?

In Step 02, choose “Forms & documents” → “Square photo (600 × 600)”. If your form also has a file-size limit, enable “Try to fit a file-size limit” and enter the required KB limit. Requirements differ by application, so check the official portal for the exact dimensions, background, dress code and maximum file size before uploading.

Step 02 mein “Forms & documents” se “Square photo (600 × 600)” select karein. Agar form par file-size limit bhi di gayi hai to “Try to fit a file-size limit” on karke required KB enter karein. Har application ki requirements mukhtalif ho sakti hain, is liye upload se pehle official portal par dimensions, background, dress code aur maximum file size check kar lein.

Can I make an image 100 KB or another specific size?Kya image ko 100 KB ya kisi aur khaas size tak la sakta hoon?

Enable “Try to fit a file-size limit”, enter your target in KB, and export. PixelFit adjusts compression and can also reduce dimensions if you enable “Reduce dimensions if needed”. This is best-effort, not a guarantee for every image. Read the result message and check the downloaded file size before submitting it.

“Try to fit a file-size limit” on karein, target KB mein likhein aur export karein. PixelFit compression adjust karta hai; “Reduce dimensions if needed” on ho to dimensions bhi chhoti kar sakta hai. Har image ke liye target ki guarantee nahi hoti. Result ka message aur downloaded file ka actual size check kar ke hi form par submit karein.

What if part of my photo gets cropped when making a desktop wallpaper?Desktop wallpaper banate waqt photo ka hissa cut ho jaye to kya karoon?

Choose “Fit entire image” if you want to keep the whole picture; this may leave margins. Choose “Fill & crop” to cover the whole frame edge-to-edge, but some edges may be cut off. You can choose a background color for the empty margins.

Agar poori tasveer bachani hai to “Fit entire image” select karein; is se sides par khaali margins aa sakte hain. Screen ko poora bharna ho to “Fill & crop” select karein, lekin tasveer ke kuch kinare cut ho sakte hain. Khaali margins ke liye background color bhi select kar sakte hain.

Are my personal photos uploaded or saved on a server?Kya meri personal photos kisi server par upload ya save hoti hain?

PixelFit processes the selected image locally in your browser and does not upload the image to PixelFit. The website itself is delivered by its hosting provider, and your device and browser security still matter. Avoid using a shared or untrusted device for sensitive photos.

PixelFit aapki select ki hui image ko browser mein locally process karta hai aur image ko PixelFit par upload nahi karta. Website khud hosting provider se load hoti hai, aur aapke device aur browser ki security bhi aham hai. Sensitive photos ke liye shared ya ghair-motabar device istemal na karein.

Which image formats can I convert?Main kin image formats ko convert kar sakta hoon?

You can export to JPG/JPEG, PNG or WebP. JPG and WebP are useful when a smaller file is needed; PNG can preserve transparency. When converting a transparent image to JPG, the transparent area is filled with the selected background color.

Aap JPG/JPEG, PNG ya WebP mein export kar sakte hain. Chhoti file ke liye JPG aur WebP useful hain; PNG transparency rakh sakta hai. Transparent image ko JPG mein convert karte waqt transparent hissa aapke select kiye hue background color se fill hota hai.

Is PixelFit free, and do I need to create an account?Kya PixelFit free hai, aur account banana zaroori hai?

PixelFit’s current tools are free to use and do not require an account, API key or separate app installation. Open the website in a modern browser, choose your image, adjust the settings and download the result.

PixelFit ke mojooda tools free hain aur account, API key ya alag app install karne ki zaroorat nahi. Website modern browser mein kholein, image select karein, settings adjust karein aur result download kar lein.

How do I remove an image background?Image ka background kaise remove karoon?

Open “Remove background”, choose a JPG, PNG or WebP photo, and select “Remove background”. The first use downloads the browser-based AI engine and its model; your photo itself is not uploaded to PixelFit. When it finishes, download a transparent PNG or choose a white, blue or custom background.

“Remove background” section kholein, JPG, PNG ya WebP photo select karein aur “Remove background” dabayein. Pehli dafa browser AI engine aur model download karega; aapki photo PixelFit par upload nahi hoti. Kaam complete hone par transparent PNG download karein ya white, blue ya custom background select karein.

Does the background remover work without an internet connection?Kya background remover internet ke baghair chalta hai?

An internet connection is needed the first time to download the AI engine and model. The browser may reuse cached files on later visits, but offline availability depends on the browser cache and device storage.

Pehli dafa AI engine aur model download karne ke liye internet chahiye. Baad mein browser cached files dobara use kar sakta hai, lekin offline chalna browser cache aur device storage par depend karta hai.
